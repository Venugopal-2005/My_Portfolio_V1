## Quick Start (Local Development)

### 1. Backend (FastAPI)

```bash
# Create virtual environment
python -m venv backend/venv

# Activate (Windows PowerShell)
backend\venv\Scripts\Activate.ps1

# Install dependencies
pip install -r backend/requirements.txt

# Start API server (auto seeds database on first run)
cd backend
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

Backend runs at: **http://127.0.0.1:8000**  
Swagger UI: **http://127.0.0.1:8000/docs**

### 2. Frontend (React + Vite)

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at: **http://localhost:5173**

### 3. Run Tests

```bash
cd backend
venv\Scripts\pytest tests/test_api.py -v
# Expected: 14 passed
```

### 4. Docker Compose (Full Stack with PostgreSQL)

```bash
docker-compose up --build
```

- Frontend: http://localhost:80
- Backend: http://localhost:8000
- Swagger: http://localhost:8000/docs

## Environment Variables

Create `backend/.env`:

```env
PROJECT_NAME="Venugopal K Portfolio API"
VERSION="1.0.0"
API_V1_STR="/api"
DATABASE_URL="sqlite:///./portfolio.db"
ENVIRONMENT="development"
CONTACT_RECEIVER_EMAIL="venu170305@gmail.com"
CORS_ORIGINS=["http://localhost:5173", "https://my-portfolio-v1-topaz.vercel.app"]
```

For PostgreSQL production:
```env
DATABASE_URL="postgresql://user:password@localhost:5432/portfolio_db"
ENVIRONMENT="production"
```

## Deployment

### Vercel (Frontend)
```bash
cd frontend
npm run build
# Upload dist/ to Vercel
```

### Railway / Render (Backend)
- Set `DATABASE_URL` to a PostgreSQL instance
- Set `ENVIRONMENT=production`
- Start command: `uvicorn app.main:app --host 0.0.0.0 --port 8000`
